# Web 安全

## SQL 注入

**原理**：程序把用户输入直接拼接进 SQL 语句，数据库看到的是拼接后的整条语句，无法区分数据与代码。单引号会破坏引号配对造成语法错误；`1' or '1'='1` 则提前闭合字符串，使后续内容变成 SQL 语法。

**分类**（按数据如何回显）：

| 类型 | 数据出口 |
|---|---|
| 联合注入 | 页面直接回显查询结果 |
| 报错注入 | 数据出现在数据库报错信息中 |
| 盲注 | 无回显，靠布尔真假或响应时间逐字符判断 |

**防御**：预编译（参数化查询）是根治手段，让输入永远作为数据填充；辅以输入校验、数据库最小权限、关闭错误回显、WAF。

**DVWA 复现（Low）**：

```sql
1' order by 2 #                      -- 判断列数
1' union select 1,2 #                -- 找显位
1' union select database(),user() #  -- 取库名和当前用户
```

## XSS

跨站脚本，向页面注入 JS 在他人浏览器执行。分反射型、存储型、DOM 型。

防御：按上下文做输出编码，配合 CSP 与 Cookie 的 HttpOnly。

## CSRF

跨站请求伪造，借用用户已登录的 Cookie 发起非预期请求。

防御：CSRF Token、Cookie 的 SameSite 属性、校验 Referer、敏感操作二次验证。

## 文件上传

防御：后缀白名单、重命名、存储到 Web 目录之外、校验文件头、上传目录禁止执行脚本。

## 越权

水平越权：同角色访问他人数据。垂直越权：低权限执行高权限操作。
防御：服务端每次校验数据归属与角色，不能只靠前端隐藏。
