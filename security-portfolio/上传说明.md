## 三、推到 GitHub（命令行方式）

### 1. 先在 GitHub 网页上建仓库

- 仓库名建议：`security-portfolio`
- **不要勾** Add a README（我们本地已经有了）
- 可见性：**Public**（简历要能点开）

### 2. 本地操作

```bash
cd security-portfolio

git init
git add .
git commit -m "安全服务练习作品集：渗透报告、DVWA 漏洞实战、资产梳理"

git branch -M main
git remote add origin https://github.com/你的用户名/security-portfolio.git
git push -u origin main
```

> 第一次 push 会让你输账号密码，现在 GitHub 要用 **Personal Access Token**（在 Settings → Developer settings → Personal access tokens 里生成），不能用登录密码。

### 3. 验证

浏览器打开 `https://github.com/你的用户名/security-portfolio`，能看到 README 的渲染效果就成了。

**注意**：GitHub 对中文文件名和文件夹名的显示是正常的，但 URL 里会变成 `%E5%AE%89%E5%85%A8...` 这种编码，**这是正常的**。

## 四、把地址填回简历

两处：

1. 简历表头：`GitHub：github.com/你的用户名/security-portfolio`
2. 证书与其他这一行：`GitHub 维护渗透靶场复盘与报告仓库` → 可以改成 `GitHub：安全服务练习作品集（含渗透报告与漏洞复现）`

## 五、几个建议

1. **README 是门面**。HR 点进来只看前 30 秒，所以首页第一屏必须是"我做过什么"的表格。
2. **每个子目录都要有 README**。别人点进某个文件夹，不应该看到一堆不知道是什么的文件。
3. **不要传大文件**。靶场镜像、虚拟机文件不要传，GitHub 单文件上限 100MB。
4. **持续更新**。之后每做完一个靶机、写完一份报告就往里加一条——这个仓库会变成你最好的简历。

## 六、如果不想用命令行

GitHub 网页支持直接拖拽上传：

1. 打开仓库页面 → **Add file → Upload files**
2. 把 `security-portfolio` 文件夹里的内容拖进去
3. 填 commit message → Commit changes

**缺点**：文件夹结构要手动保持一致，容易漏。文件名带中文时偶尔会有编码问题。

命令行更稳，建议用命令行。
