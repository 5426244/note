## 我给自己定的学习方法

**只看不练等于没学，只练不思也无法迁移。**

每学一个知识点，必须做到三件事：

1. **动手敲一遍**（命令类）
2. **用自己的话说出它证明了什么**（原理类）
3. **写一句"它防住了什么 / 它为什么成立"**

## 踩过的坑（部分）

| 错误 | 原因 | 教训 |
|---|---|---|
| `sudo /var/log/auth.log` | `sudo` 后面要跟命令，不是文件 | 命令结构是「命令 + 选项 + 参数」 |
| `ping 193.168.59.2` | IP 打错一位 | 先确认地址，再怀疑网络 |
| `ssh 1@192.168.59.128` | 用了 Windows 的用户名 | `@` 前面是目标机器的用户 |
| `nmap -sn 192168.59.0/24` | 少一个点 | 报 `Failed to resolve` 八成是地址写错 |
