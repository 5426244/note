# Metasploitable 2 渗透测试（个人练习）

## 概述

对 Metasploitable 2 靶机做完整的黑盒渗透测试，从信息收集到漏洞验证，最终输出结构化报告。

- **测试时间**：2026.10
- **测试对象**：Metasploitable 2（本地 VMware 虚拟机）
- **测试方式**：黑盒，未获取源码
- **报告**：[Metasploitable2_渗透报告与面试讲法.docx](./Metasploitable2_渗透报告与面试讲法.docx)

## 做了什么

1. **信息收集**：Nmap 全端口扫描（`-sV`）识别出 25 个开放服务
2. **攻击面筛选**：按「版本陈旧」和「服务类型」两个维度，从 25 个服务里筛出高优先级目标
3. **漏洞验证**：确认并利用 3 个漏洞
   - TCP 1524 未授权 root shell
   - vsftpd 2.3.4 后门命令执行（CVE-2011-2523）
   - MySQL root 空口令（可读 7 个库）
4. **输出报告**：8 页，含信息收集、漏洞详情、未验证风险点、P0/P1/P2 分级修复建议

## 收获

- **信息收集是第一步，也是最重要的一步**。25 个服务里真正有价值的就那么几个，筛选能力比扫描能力更重要。
- **同一个靶机，漏洞的严重程度差别很大**。vsftpd 后门是版本本身的问题，MySQL 空口令是配置问题——修复思路完全不同。
- **报告要写清楚「未验证的部分」**。不是所有可疑点都能验证，如实标注反而显得专业。

## 注意

靶机环境，漏洞是故意留的。真实环境中任何利用行为都必须获得明确授权。
